Projects

UESerial Library

A custom Arduino library written to allow communication between an Arduino and an Unreal Engine 5.3 plugin. I wrote this by myself in order to aid the HPU Minds club in their phobia exposure therapy project. It contains several functions that facilitate the communication, and supports all standard datatypes.

UESerial

GSR_Stress Library

A custom Arduino library written to take and interpret Galvanic Skin Response readings from a sensor for use with an Arduino. It has full capability to take baselines and to determine a user's stress/fear levels by comparing it to their baseline. It is a set of useful functions for use with GSR sensors.

GSR_Stress

HPU Minds Fear Project

A project undertaken by the HPU Minds club that I contributed heavily to. It's goal is to create a VR exposure therapy environment for people with arachnophobia that detects and adjusts to a participant's fear levels in real time. It uses both an Arduino as well as an Unreal Engine 5 environment.
