Courses

Computer Science

Intro. to Computer Programming
An introduction to the fundamentals of programming using a high-level, structured programming language such as C. Emphasis was placed on syntax and semantics of the language to write correct, efficient, and easily modifiable programs. Topics included, but were not limited to, assignment statements, conditional and iterative control structures, functions, simple data structures, and software development.
Adv Prog With Data Structures
A continuation of the previouse course covering more advanced fundamentals of programming including problem-solving strategies, the concept of an algorithm and basic data structures in an object-oriented language such as C++. Various programming concepts were introduced such as recursion, string processing, classes, sorting, searching, linked lists, stacks, queues, and trees.
Database Systems
This course covered database design and the use of databases in web, mobile and cloud applications. It included extensive coverage of the relational model, relational algebra, and SQL as well as NoSQL designs. The course also featured database design and relational design principles based on dependencies and normal forms. There was a programming project, which explored database design and management by utilizing appropriate features of SQL.
Web Technologies
A study of advanced web technologies with an emphasis on full stack development including usage of a database to facilitate the retention and delivery of information. Various scripting languages such as PHP and JavaScript were used during the course
Discrete Structures
An introductory course in discrete mathematical structures widely used computer science. The purpose of this course was to understand and use (abstract) discrete structures that are backbones of computer science. This course tought techniques in how to think logically and mathematically and apply these techniques in solving problems. In particular, this class introduced logic, proofs, sets, relations, functions, counting, and probability, with an emphasis on applications in computer science.

Mathematics

Intro Statistical Analysis
This course was a calculus-based introduction to statistics. Topics included: populations; sampling; random variables and their distributions; sampling distributions; one- and two-sample inference, and simple linear regression.
Intro to Mathemat Thought
Introduction to Mathematical Thought. An introduction to mathematical proof. Topics include elementary symbolic logic, mathematical induction, algebra of sets, finite probability, relations, functions, and countability.
Linear Algebra
Linear Algebra. Systems of linear equations and matrices, determinants, vector spaces and inner-product spaces, linear transformations, eigenvalues and eigenvectors. The emphasis was on computational techniques and applications.
Calculus II
Integration: techniques and applications to geometry, physics, economics, and probability. Sequences, series, power series, Taylor's Theorem, and elementary differential equations.
Calculus III
Vectors and geometry in space. The dot and cross products, lines, planes, surfaces in space. Calculus of vector functions, including functions of several variables, partial derivatives, gradients, directional derivatives, maxima and minima. The course also covered multiple integration, line and surface integrals, Green's Theorem, Divergence Theorems, Stokes' Theorem, and applications.
Geometry
Geometry. Incidence and affine geometry, parallel postulates, Euclidean and non-Euclidean geometry. Models and the development of Euclidean geometry.
